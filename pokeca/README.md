# ポケカ相場トラッカー

登録したカードの相場を GitHub Actions で毎日 (09:17 JST) 記録し、チャートを更新します。

- カードの登録: `cards.json` に追記 (Claude に「〇〇を登録して」と頼めば追記します)
- 登録時はスニダンの取引履歴から **発売日以降の全期間** を自動で遡って記録します
- カードラッシュ販売価格・スニダン最安出品は履歴が取れないため、登録日以降の記録です
- 生データ: `data/<id>.json`
