# 案件ボード（試作 STEP 0）

営業企画課の案件・タスク管理アプリの試作版です。`/anken` 以下で動きます。メダカのアプリ（`/`）とは独立しています。

## 動かし方

```bash
npm install
npm run dev
# http://localhost:3000/anken を開く
```

## 画面

| パス | 内容 |
| --- | --- |
| `/anken` | ホーム。右上で A ボール中心 / B カレンダー中心 / C カンバン を切り替え |
| `/anken/inbox` | 受付箱。依頼を案件化するとテンプレートの工程が納期から逆算して作られる |
| `/anken/board` | カンバン。「クライアント・外注待ち」列に入れるとボールを渡す相手を選ぶ |
| `/anken/timeline` | 案件ごとの日程と、担当者別の負荷 |
| `/anken/projects` | 案件一覧と案件詳細（タスク、関係者、確認リンク、やりとり） |
| `/anken/settings` | ホーム表示、手持ちタスクのまとめて登録、メンバー・相手先の編集、サンプルに戻す |
| `/anken/review/[taskId]` | 社内クライアント・外注先がリンクから開く確認画面（OK / 修正依頼） |

## 仕組み

- データは `zustand` の `persist` でブラウザの localStorage（キー `anken-board-v1`）に保存。共有はされない。
- サンプルデータ（`sample.ts`）は「今日」からの相対日付で作るので、いつ開いても同じ状況になる。
- 工程テンプレートは `templates.ts`。STEP 1 で設定画面から編集できるようにする予定。
- 「ボール」は `Task.ballId`。相手先（社内クライアント・外注先）に渡すと状態が「待ち」になり、`ballSince` から待ち日数を数える。
